# Contributing

Start by running `python tests/check_package.py` and `python examples/run_bandit.py`.

Expressive contributions: new scripted poses/behaviors, clearly marked as supported-base demos rather than balance controllers.

Physics contributions: contact tests and free-body simulations, with assumptions documented.

Locomotion contributions: observation/action mapping, actuator compatibility, and validated standing/walking policies. No locomotion support is claimed in v0.1.

Design contributions: use `blender/README.md`; retain original editable project and provide optimized exports separately.

Do not commit personal computer paths, secrets, generated caches, or unlicensed third-party assets.
